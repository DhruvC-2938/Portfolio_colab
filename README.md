# Prompt : 
Create a complete AI-powered Portfolio Management and Resume Generator in Google Colab using Python, Gemini API, SQLite, Google Sheets API, Gradio, and ReportLab. Requirements: 1. Store personal information, education, skills, certifications, projects, experience, achievements, publications, and languages in a structured database. 
2. Use Gemini to organize portfolio data, analyze job descriptions, extract keywords, match relevant skills and projects, and suggest resume improvements.
3. Export and synchronize portfolio data with Google Sheets using separate tabs for each category. 
4. Build an interactive Gradio UI to manage portfolio records, paste job descriptions, select or deselect resume sections, edit summaries, and preview resumes.
5. Generate downloadable, professional PDF resumes that update whenever the job description or selections change. 
6. Prevent AI hallucinations by including only verified information from the portfolio database. 
7. Use sample data and test two different job roles, generating two customized resumes from the same portfolio.
8. Include error handling, secure API key configuration, database schema, setup instructions, and a short README. Generate executable notebook cells in order, with minimal manual configuration. Do not use pseudocode or fake integrations. Clearly explain Google authentication and verify that Gemini, Google Sheets synchronization, and PDF downloads work.
